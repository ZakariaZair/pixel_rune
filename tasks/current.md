## Widget testing workflow

This project needs a generated iOS native project or EAS Build to validate the
WidgetKit target. Expo Go cannot run this widget.

1. Generate native iOS files locally:

   ```bash
   npx expo prebuild --platform ios
   ```

2. Open `ios/PixelRune.xcworkspace` in Xcode.
3. Confirm the generated targets include the app target and `PixelRuneWidget`.
4. In Apple Developer capabilities, confirm App Groups includes
   `group.com.pixelrune.app` for both targets.
5. Build and run the app on an iOS simulator or device.
6. Add the small `Pixel Rune` widget to the home screen.
7. Select a Rune in the app. The app writes the active Rune payload to
   `activeRunePayload` in App Group `UserDefaults` and requests a widget
   timeline reload.
8. If the widget still shows the fallback Rune, remove/re-add the widget or wait
   for iOS to process the timeline reload; WidgetKit refresh timing is not
   guaranteed to be instant.
